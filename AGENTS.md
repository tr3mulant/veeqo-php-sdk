## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on tr3mulant/veeqo-php-sdk via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Branching

Branches are `feat/`, `fix/`, `docs/` or `chore/`, with the issue number when there is one; worktrees live in `.agents/worktrees/`. See `docs/agents/branching.md`.
