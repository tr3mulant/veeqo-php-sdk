# Veeqo PHP SDK

A PHP/Laravel client for the Veeqo API, used both by private integrations talking to their own Veeqo account and by Appstore apps acting on behalf of many Veeqo accounts.

## Tenancy

**Veeqo account**:
One Veeqo subscription and everything in it; the scope every credential is bound to. The API calls it a Company.
_Avoid_: seller, company, tenant, organisation

**Seller**:
The business or person operating a Veeqo account. Used in prose only, never as an identifier, because one seller may run several Amazon Seller Central accounts inside one Veeqo account.
_Avoid_: using it to mean a Veeqo account or a Seller Central account

**User**:
A login within a Veeqo account. A Veeqo account may have several users, each able to generate their own API key.

**Channel**:
A sales channel connected to a Veeqo account, such as an Amazon Seller Central account or a Shopify store. The API calls it a Store.
_Avoid_: store, marketplace, seller account

## Integration kinds

**Private integration**:
Software built by a seller to talk to their own Veeqo account only.
_Avoid_: internal app, personal integration

**Appstore app**:
Third-party software listed on the Veeqo Appstore that acts on behalf of many Veeqo accounts, each of which grants it access.
_Avoid_: public app, OAuth app, marketplace app

## Credentials

**API key**:
A long-lived secret generated by a user that grants full access to their Veeqo account; the credential a private integration uses.
_Avoid_: token, secret

**Access token**:
A permanent credential issued to an Appstore app when a Veeqo account approves it; one per Veeqo account.
_Avoid_: API key, bearer key, OAuth key
